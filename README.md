\# Slider



Приложение для показа плейлистов из изображений и видео на Windows.



\## Возможности



\- Добавление фото и видео в плейлист.

\- Drag \& drop файлов прямо в окно программы.

\- Визуальный overlay при перетаскивании файлов.

\- Разделение плейлиста на периоды с датой и временем начала и окончания.

\- Автоматическая установка даты нового периода на следующий день после предыдущего.

\- Плавные переходы между изображениями и видео без ухода в чёрный экран.

\- Сохранение и повторное открытие плейлистов.

\- Корректная работа с плейлистом после его перемещения в другую папку или на другой компьютер.
