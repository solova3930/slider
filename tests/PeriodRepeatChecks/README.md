Проверки функции «Повтор периода» запускаются на Windows с .NET 8 SDK или новее:

```powershell
dotnet run --project tests/PeriodRepeatChecks -c Release
```

Без внешних тестовых пакетов: проверяются модель, совместимость JSON, сохранение,
обработчики ввода и вставки, колесо мыши, автосохранение, выбор/добавление/удаление
периодов, последовательности показа (1, 2, 3 и 99 раз), смена расписания,
перезапуск, остановка таймеров и недоступные изображения.
Проверки вызывают обработчики WPF на STA-потоке, включая удаление периода без подтверждения.
Рендеры панели при двух размерах сохраняются в `bin/Release/net8.0-windows/checks`.
Воспроизведение реальных видео и захват FFmpeg в эти проверки не входят.
